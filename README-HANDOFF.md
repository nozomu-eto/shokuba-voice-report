# Codex引き継ぎパック — 職場の声レポート

1. Next.js初期化・pnpmでの起動確認が済んだローカルの `shokuba-voice-report` フォルダを開く。
2. このパックの `AGENTS.md`、`docs/`、`fixtures/` を**プロジェクトルート**へコピーする。既存の同名ファイルがあれば上書きせず、内容を統合する。
3. Gitを初期化していない場合は `git init`、その後 `git add . && git commit -m "chore: initialize Next.js project"`。Git設定未完了ならこの手順は飛ばしてよい。
4. Codexの作業ディレクトリを当該プロジェクトに設定し、モデル/思考レベルは利用者側で指定する。
5. `docs/CODEX_START.md` をCodexに貼り付けて実装依頼する。Codexは最初に`AGENTS.md`も読むよう指示されている。
6. Codexの完了報告後に `pnpm dev` で画面を目視確認する。AWSアクセスは不要。

このパックはユーザーの既存Next.jsプロジェクトを変更していません。ユーザー自身がローカルにファイルをコピーする必要があります。

**注意**: このパックのCSVヘッダーは暫定設計です。以前のMVP設計原本やv0.7 UI試作の実ファイルは、この引き継ぎパックには含まれていません。原本を持っている場合はCodexに追加して差分を確認してください。
