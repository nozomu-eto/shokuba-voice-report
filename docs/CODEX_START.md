# 初回Codex依頼文（コピペ用）

このリポジトリで「職場の声レポート」のMilestone 1を実装してください。

最初に `AGENTS.md` と `docs/IMPLEMENTATION_BRIEF.md` を読み、`package.json` / `src` / 現在のGit状態を確認してください。既存のNext.js・TypeScript・Tailwind環境を尊重し、pnpmだけを使用してください。

**今回のゴールは、サンプルデータまたはローカルCSVを読み込み、数値集計と根拠付きサンプルAI分析をブラウザで見せられる「動作する最小アプリ」です。**

実装範囲:
1. 同梱 `fixtures/employee-survey-sample.csv` のロードと、ユーザーのCSVローカル読み込み。BOM、引用符、カンマ、列不足、不正な整数、重複ID、空データに対応し、分かりやすい日本語エラーを出す。
2. 回答件数と4項目平均をTypeScriptで正確に計算する。表示は小数第1位。異常値を黙って補正しない。
3. **同梱のサンプルCSVを選んだ場合に限り**、`fixtures/ai-analysis-mock.json` に基づく事前生成AI分類を明示的に「サンプルAI分析」として表示し、根拠回答IDから原文を確認できるようにする。アップロードしたCSVに対して、サンプルAI結果をそのデータの結果のように表示してはいけない。
4. 日本語で分かりやすいレスポンシブUIを作る。対象は小規模企業の人事担当者。余白、読みやすさ、キーボード操作を重視する。
5. CSVパース、バリデーション、平均計算、根拠ID検証とサンプル表示制御に自動テストを作成する。必要なら最小限の依存ライブラリを追加してよいが、理由を説明する。
6. READMEに使い方、CSV仕様、サンプルと実データの違い、未実装項目を記載する。

制約:
- AWS APIの実行、Bedrockの呼び出し、AWSリソース変更、デプロイ、認証情報の取得・発行・保存は**一切禁止**。AWS操作・有料実行は必ず事前承認が必要で、今回は許可していない。
- DB、ログイン認証、課金、ストレージ、外部AI API、派手なUIコンポーネント群は追加しない。
- 今回は報告書PDF、Bedrock統合、Amplifyデプロイへ進まない。
- 原本の古い設計ファイルがない場合は、`docs/IMPLEMENTATION_BRIEF.md` にあるCSVスキーマが暫定であることを踏まえて実装する。

完了条件:
- `pnpm dev`で画面が動く。
- `pnpm exec tsc --noEmit`、lint（利用可能なら）、テスト、`pnpm build` が成功する。失敗した場合は原因と残課題を明記する。
- 変更したファイル、追加した依存パッケージ、動作確認結果、既知の制約を報告する。
