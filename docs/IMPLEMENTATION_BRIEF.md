# 職場の声レポート — Codex向け実装ブリーフ v1

作成日: 2026-11-11

## 目的と利用者
- ポートフォリオ用MVP。中小企業などの人事担当者が、従業員アンケートのCSVから、数値サマリーと自由記述の傾向を確認し、報告書として活用する。
- 画面は日本語。PCが得意でない利用者にも分かる簡潔な導線。高度な設定画面を増やさない。
- 採用評価のための見せ場は、業務フローの完結、正しい数値集計、根拠付きAI出力、人間の確認、テスト、実装判断。

## 技術前提
- ユーザーが作成・起動確認済みの `shokuba-voice-report` リポジトリ。
- Next.js App Router、TypeScript、Tailwind CSS、pnpm。
- 最初は**完全ローカル**。DB、認証、AWS SDK、S3、DynamoDB、Amplify、課金、ログ基盤は導入しない。

## MVP完成形と、最初の作業を区別する
**最初のCodex実装（Milestone 1）**
1. 架空のサンプルCSVを読み込む／ユーザーCSVをローカルで取り込む
2. CSV検証と決定論的な数値集計
3. サンプルに限って事前生成のAI分類・要約を表示し、根拠回答へリンクする
4. レスポンシブな日本語UI、テスト、README

**次の段階（今回着手しない）**
5. 編集可能な報告書とA4印刷/PDF保存（ブラウザ印刷で十分）
6. Bedrock `Converse` をサーバー側へ安全に接続する実装。ただし**実際のAWS接続・呼び出しは個別事前承認後**
7. 専用Amplifyアプリのデプロイと費用確認（要個別事前承認）

## 第1段階の画面案
- ヘッダー: 「職場の声レポート」、短い目的説明、サンプルデータ表示
- ステップ1: 「サンプルで試す」および「CSVを選択」ボタン。CSV形式の簡単なヘルプ
- ステップ2: 対象回答数・4問の平均（質問名とともに表示、平均は小数第1位）
- ステップ3: サンプルCSVの場合のみ「サンプルAI分析（事前生成・デモ用）」としてテーマ・要約・根拠回答IDを表示。IDを選ぶと対応する自由記述が読める
- 読み込んだ別データの場合: AI分析を装わず「アップロードしたCSVのAI分析は現在利用できません。数値集計のみ表示しています」と表示
- エラー: 不正な行・列・評価の値を示し、利用者が直しやすい日本語

## CSVの暫定スキーマ（既存仕様の原本が未添付のため暫定）
添付 `fixtures/employee-survey-sample.csv` を実装初期の基準とする。

| CSV列 | 内容 | 制約 |
|---|---|---|
| `回答ID` | 各行を区別するID | 必須、重複不可 |
| `働きやすさ` | 評価1 | 1〜5の整数 |
| `相談しやすさ` | 評価2 | 1〜5の整数 |
| `情報共有` | 評価3 | 1〜5の整数 |
| `継続意向` | 評価4 | 1〜5の整数 |
| `自由記述` | コメント | 空欄を許可（AI分類根拠には使わない） |

- UTF-8、BOM対応。引用符内のカンマ、改行にも適切に対応すること。
- 入力は明示的に検証し、無理な数値変換（空欄→0など）はしない。
- 最初はCSVの列順に依存せずヘッダー名でマッピングする。
- 大量ファイルを無制限に扱わず、適切なサイズ制限と説明を設ける。
- 既存設計の正規CSVスキーマが後から提供された場合、仕様とテストを合わせて更新する。

## 数値の基準値
同梱CSVは3回答。
- 働きやすさ: (4+2+4)/3 = 3.33...
- 相談しやすさ: (2+2+4)/3 = 2.66...
- 情報共有: (3+2+4)/3 = 3.0
- 継続意向: (4+3+4)/3 = 3.66...
画面では小数第1位で表示。丸める前の集計値を保持する。

## サンプルAI結果
`fixtures/ai-analysis-mock.json` は、東京リージョンのAmazon Nova Liteに**2026-11-11に架空回答3件を1回送って得られた結果を整形した静的フィクスチャ**。モデルの成果の例であり、任意の新規CSVに対する推論結果ではない。

- R001: 部署による業務手順差
- R002: 繁忙期の相談先不足
- R003: 週次ミーティングの情報共有効果
- 生成テキストは必ず元の架空回答から根拠が確認できるようにする。
- `response_ids` が未知のIDを含むケースをテストして拒否または問題として表示する。

## 重要な境界
- アプリの公開デモでAIが毎回実行されるように見せない。
- 実データの保管・送信をしない。
- AIは集計値を作らない。根拠未確認の主張を事実として書かない。
- 今回のM1はBedrock接続なし。ユーザーのAWSプラグインはroot接続のため、資格情報をCodexに渡さない。

## UI方針
- 白背景と青・緑の落ち着いたアクセント。大きな見出し、本文16px以上、クリック領域は約48px。
- 読めるコントラスト、キーボード操作、フォーカス表示、フォームの明示的な説明。
- スマートフォンでも1列でレイアウトが破綻しない。
- 競合評価・市場調査・追加機能よりも、既存MVPの品質と完成度を優先。
