# 職場の声レポート

中小企業などの人事担当者が、従業員アンケートの回答を集計し、自由記述の参考分類と根拠を確認して報告書にまとめる流れを試すポートフォリオ用デモです。採用担当者には、入力検証、決定論的な集計、AI出力の境界、人による確認を一続きで見てもらえます。

## 主な機能

- 同梱の架空CSVを読み込み、回答件数と4項目の平均を表示
- ローカル開発モードでは、UTF-8 CSVをブラウザ内で検証・集計
- サンプルに限り、事前生成のAI参考分析と根拠回答IDを表示し、元コメントを確認
- 数値を読み取り専用に保ちながら、報告書のタイトルと本文を編集
- A4縦の印刷レイアウトからブラウザの「PDFとして保存」を利用

## 技術構成

- Next.js 16 App Router、React 19、TypeScript
- Tailwind CSS 4
- pnpm、Node.js組み込みテストランナー
- AWS SDK、データベース、認証、外部AI APIは未導入

## 起動とデモ

開発環境はNode.js 22.6以上（推奨24.11.1）、pnpm 12.9.1です。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

ブラウザで <http://localhost:3000> を開き、「サンプルで試す」を押してください。公開用のproductionビルドではCSV選択欄を表示せず、同梱サンプルのみを使うモードになります。環境変数による切り替えはありません。`pnpm dev`のローカル開発時だけCSV選択が使えます。ローカルCSVも架空データを使ってください。

## CSVの暫定スキーマ

以下の6列を見出し名で認識します。列順は任意です。

| 列 | 条件 |
| --- | --- |
| `回答ID` | 必須、空欄・重複不可 |
| `働きやすさ` | 必須、1〜5の整数 |
| `相談しやすさ` | 必須、1〜5の整数 |
| `情報共有` | 必須、1〜5の整数 |
| `継続意向` | 必須、1〜5の整数 |
| `自由記述` | 列は必須、値は空欄可 |

UTF-8（BOM可）、引用符内のカンマ・改行・二重引用符に対応し、上限は2 MiBです。このスキーマは暫定スターター仕様であり、過去の正式仕様との照合は済んでいません。詳細は [`docs/CSV_SCHEMA.md`](docs/CSV_SCHEMA.md)、サンプルは [`fixtures/employee-survey-sample.csv`](fixtures/employee-survey-sample.csv) を参照してください。

## 数値とAI参考情報

回答件数・合計・平均は検証済み回答からTypeScriptコードで計算します。平均は内部では丸めず、表示時だけ小数第1位にします。AI出力は数値を計算しません。

「サンプルAI分析（事前生成・デモ用）」は同梱の架空データ向けの静的フィクスチャで、現在の画面からAI推論を実行しません。表示前に根拠IDの存在・重複・コメントを検証し、根拠本文は元回答から表示します。これは形式と出典の対応を確認するもので、文章の意味的な正しさを保証するものではありません。利用者が原文を読み、必要な判断をしてください。アップロードデータには静的AI分析を表示しません。

## 安全性の設計

- productionと未知の実行環境は公開モードとして扱い、同梱架空サンプルのみ利用可能です。開発用環境変数の設定ミスでアップロードが有効になる構成にはしていません。
- ローカル開発モードのCSVはブラウザ内で処理され、アプリから送信・永続保存しません。
- Bedrock準備コードはサーバー専用境界に置かれ、公開画面から参照されません。AWS SDK、実アダプター、API実行UI、推論呼び出しはありません。
- 実在する従業員データ、個人情報、社内資料、認証情報をデモやテストに使用しないでください。

- このアプリを実データの従業員情報処理や本番業務に使用しないでください。
